# Coding Conventions & Testing Standards

## Clean Code Principles
- Keep changes minimal and concise; the best code is the code never written.
- Follow existing patterns and libraries already present in the workspace.
- Self-documenting code with meaningful names; comment only the non-obvious "why".

## Testing Standards
- Automated test execution evidence is mandatory before marking any task complete.
- Follow the Testing Pyramid: Unit > Integration > E2E.
- Every new branch or bug fix requires an automated regression test.
- AAA Pattern (Arrange, Act, Assert) for test clarity.
